# 🛡️ SafeNav — Crime Hotspot Detection & Safe Route Navigation

SafeNav is a smart navigation system that analyzes crime data to detect high-risk zones and recommend the safest possible route for users. It combines mapping, data analytics, and machine learning to ensure safer navigation in cities.

---

## 🚀 Features

### 🔍 Crime Hotspot Detection
- Visualizes crime-prone areas on an interactive map.
- Heatmaps generated using clustering (K-Means / DBSCAN).
- Uses historical and real-time crime data.

### 🗺️ Safe Route Recommendation
- Evaluates different navigation routes.
- Avoids red/high-risk areas and suggests safer alternatives.

### 📍 Location-Based Risk Assessment
- Computes a **Safety Score** based on crime severity.
  
### 📊 Crime Data Analytics Dashboard
- Shows crime distribution over time.
- Crime count by category and region.
- Graphs and charts via backend APIs.
